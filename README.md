# 🎲 Dice Game

Welcome to the **Dice Game** – a fun and interactive web-based game where two players roll the dice, and the one with the higher number wins! It's a simple game of chance, perfect for quick entertainment and learning how JavaScript DOM manipulation works.

🌐 [Live Demo](https://harshavardhan-github.github.io/dicegame/)

---

## 🧩 Game Overview

- Two players each roll a die.
- The dice faces are randomly generated using JavaScript.
- The player with the higher roll wins.
- In case of a tie, the game declares a draw.

It's minimalistic, responsive, and coded for a delightful user experience.

---

## ✨ Features

- 🎲 Real-time dice rolling animation
- 🏆 Dynamic winner announcement
- 📱 Fully responsive layout
- 💡 Simple and clean UI
- 🧪 Lightweight and fast-loading

---

## 🚀 How to Use

1. Open the game in your browser using the [Live Demo](https://harshavardhan-github.github.io/dicegame/).
2. Click **Refresh** (F5) or reload the page to roll the dice.
3. See who wins – Player 1 or Player 2 – or if it’s a draw.

🔁 Keep refreshing to play again and again!

---

## 🛠️ Tech Stack

- **CSS3** – for styling and layout
- **JavaScript (ES6)** – for game logic and interactivity
